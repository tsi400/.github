# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email: **security@tsi400.com**

You should receive a response within 48 hours. We will work with you to understand the issue and coordinate a fix.

## Supported Versions

Only the latest release of each project is supported with security updates.

## Security Scanning

All repositories in this organization use automated security scanning:
- **CodeQL** — static analysis for code vulnerabilities
- **Trivy** — dependency and container vulnerability scanning
- **Snyk** — open-source dependency monitoring
- **OpenSSF Scorecard** — supply chain security health
- **Dependency Review** — PR-level license and vulnerability checks
